## 将棋
抵抗値から抵抗の回路を設計するゲームを制作中です  
教育用としても利用できるパズルゲームのようなものを制作しようと考えています。  
ノードを使ってユーザーに分かりやすい実装をできるように意識しています。  

## 画像
![開発段階画像](https://github.com/Ryoncy-Git/Resistance/blob/master/Assets/!ForReadMe/ScreenShot.png)

## 操作説明
マウス操作のみで行います。  
現在は開発途中のため、十字キー上でノードをスポーン、ポートをクリックしてノードをつなげる操作になっています。  

## 実装環境
Unity6000.0.44f1

## 実装時のこだわり
ユーザーにとって直感的に理解しやすい、操作しやすい設計を心掛けています。ノードの移動はD&Dで、ポートの接続も見た目をわかりやすくするため線を描画しています。　　
クラスの継承を使うことでノードの種類が増えても対応しやすい設計にしています。クラス間でのデータのやり取りもなるべく密接にならないよう気を付けて実装しています。　　

## 苦労したコト
ユーザーが操作する大きい箱が「ノード」ノードについている接続端子を「ポート」と呼んでUnity上では設計していますが、スクリプト内でグラフに起こす際は、大きい箱は「エッジ」接続端子を「ノード」と呼んでおり、呼び方の差異による実装コストがかかってしまっています。　　
行列式による抵抗値計算を行っています。行列式の変形や扱いがかなり難しく、とてもてこずっています。  
線の描画や更新タイミングの設計が上手くいかず、更新イベントを呼び出すタイミングや場所を変え、一度大きく設計しなおしています。  

## 今後の展望
まだ、行列計算が上手くいかず直列回路を作成すると計算不能になってしまいます。計算できるように設計しなおさなくてはならないのが課題です。  
UIやテクスチャをまだ用意していなく、遊ぶことができる見た目でもないため、見た目を整えようと考えています。  
いくつか例題を用意し、それを解くことで計算や問題になれるよう設計しようと考えています。
